# کوتاهک

سرویس کوتاه‌کننده لینک با امکان مدیریت لینک‌ها و مشاهده آمار بازدید.

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* TanStack Query
* React Hook Form
* Zod
* Axios
* ApexCharts

## Features

* ثبت‌نام و ورود کاربران
* ساخت و مدیریت لینک کوتاه
* داشبورد کاربر
* مشاهده آمار و Analytics
* مدیریت لینک‌ها

## Getting Started

ابتدا dependencyها را نصب کنید:

```bash
npm install
```

سپس پروژه را اجرا کنید:

```bash
npm run dev
```

پروژه در آدرس زیر در دسترس خواهد بود:

```text
http://localhost:3000
```
